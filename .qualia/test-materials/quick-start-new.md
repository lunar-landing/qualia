# 快速开始

本篇带你五分钟上手「资料」功能：创建资料库、上传文件、按目录阅读整篇文章。

## 安装与启动

前后端各启动一份即可：

- 后端：`mvn spring-boot:run`（qualia-code 模块，默认端口 `9090`）
- 前端：`npm run dev`（qualia-code-ui，`/api` 代理到后端）

## 第一步：创建资料

点击侧栏底部的「资料」入口，在列表页右上角点击「新建资料」。建议按团队或主题建库，例如「产品文档」「团队 Wiki」。

## 第二步：上传资料

进入资料后，点击左下角「上传资料」，或直接把文件拖进窗口。支持 `md` / `txt` / `pdf` / `docx`，其中 pdf 与 docx 会自动抽取全文转成整篇 Markdown，原件保留可随时回看。

## 第三步：阅读与导航

- 左侧是文章树，点击任意文章即可整篇阅读
- 文章内的相对链接可以直接跳转，例如 [系统架构总览](architecture.md)
- 子目录文章同样可达，例如 [部署指南](guide/deployment.md)
