两版差异点

  • 布局取向：V1 横向双栏（品牌 42% + 规格 58%），Build Info 单列键值、dashed 分隔线，工程铭牌质感；V2 纵向居中，双列网格收纳信息，与现版视觉连续性最强。
  • 新增信息：两版均补齐 构建日期 / 运行时 / 框架版本 / 快速链接（GitHub · 文档 · 反馈）；V1 额外带「检查更新」入口，V2 不带（避免承诺未实现的更新逻辑）。
  • 版本展示：V1 版本徽章独立一行（左对齐节奏）；V2 徽章与产品名同行（节省纵向空间）。
  • 数据来源：构建日期/运行时需后端在 about 接口补两个字段；拿不到时两版均可整行隐藏，不阻塞落地。

风险点

  • V1：设置弹窗内容区宽约 620px，双栏在 620px 下品牌列描述文案较长时可能挤压规格列，落地时需把 desc 控制在两行内（或弹窗加宽到 680px）。
  • V1：「检查更新」是新增交互承诺，若近期无更新检查实现，建议首版去掉该入口。
  • V2：信息增多后纵向高度接近弹窗上限，小屏（高度 < 560px）时需允许内容区滚动。
  • 共性：链接芯片的跳转目标（GitHub 仓库地址、文档站）需与 README / deploy-docs 对齐，桌面端壳内点击需走系统浏览器（BrowserPanel 已有外链转交逻辑）。
