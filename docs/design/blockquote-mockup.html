聊天气泡内的引用块 · 四个版本，右上角切换深 / 浅主题预览

现状

当前线上版（对照组）

问题：accent 边条在日间是石墨黑（过重），底色是硬编码紫色残留（浅色下泛紫）。

这个问题的原因在配置加载顺序上：

配置分两层加载：全局 ~/.qualia/code/config.json 提供默认值，工作区 .qualia/config.json 覆盖同名键。工作区配置优先级更高，且合并是浅合并。

所以你只需要在工作区放一个覆盖文件即可。

V1

经典灰条

GitHub 风格的克制方案：中性灰左条 + 极淡中性底。引用是「弱化的内容」，不抢正文视觉。最稳、最不易过时。

V2

淡底衬卡

Notion callout 风：去掉左条，整块淡灰底 + 四角圆角。块状感更强、边界更柔和，多段长引用时最整齐。与代码块的「深底」形成明暗区分。

V3

语义绿条

左条与底色都用主题绿（低饱和、低透明度），暗示「这是引用的外部声音」。与热力图、开关的亮绿体系同源，品牌感最强——但页面绿色元素会变多。

这个问题的原因在配置加载顺序上：

V4

悬垂引号

编辑部风格：Georgia 衬线大引号悬垂在左上，无边框无底色，靠排版而不是色块区分。最轻最雅，但识别度依赖字号层级，窄气泡下略挤。

说明：四个版本的文字色统一为 text-secondary（弱于正文），内部行内代码 / 加粗保持气泡内原样式；落地时将新增 --bg-blockquote / --border-blockquote 主题变量替换掉硬编码紫色，深浅两套同步生效。
