变体视觉重量信息密度适合代价
1 Git Status最低最高终端风产品调性，开发者用户字母 op 有学习成本，可 hover 提示补充中文

混用建议：默认用 变体 3（安静耐看），HTML / mockup 交付回合升级为 变体 2（产物值得仪式感）， 纯配置微调回落 变体 4。点击路由与浮层预览四种变体行为一致，可随时整体换肤。
