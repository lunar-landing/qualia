选型说明（元素轮 5 形态汇总）

形态替换元素收益风险与代价
V9 状态字母op 标识与终端模式 A/M/D 语言统一，列对齐最齐整非 git 用户需学习；字母语义依赖图例
V10 类型图标文件名类型零成本可辨，全年龄直觉需维护扩展名映射表（一次性成本）
V11 状态点op 标识色彩面积最小、行内最安静色弱不可辨；写入/修改仅一色差易误读
V12 整行可点预览入口命中区域最大、行内元素最少误触率上升；可发现性依赖 hover
V13 目录前缀文件名同名文件可区分，路径语境完整长前缀挤压文件名空间（需折叠兜底）

建议：V10 类型图标为普适收益最大的单点升级（可与 V13 叠加成终态）； 若更看重双端一致性（气泡 ↔ 终端）则选 V9；V11 / V12 属「更极简但更冒险」，仅在接受可发现性损失时采用。
