选型说明（极简版 8 形态汇总）

形态op 表达容器适合
V1 极简行着色文字hairline 行默认形态，均衡
V2 胶囊行着色文字浅底圆角暗色主题、行数多
V3 单行内联着色文字（·分隔）无单文件微改动
V4 左色条3px 刻度 + 灰字hairline 行去彩化偏好、多行色带扫读
V5 微染底色着色文字 + 淡底染色圆角行需要最快分类扫读
V6 空心徽标描边胶囊hairline 行想要标签感但保持轻
V7 分组标题组头声明分组 hairline文件数多（≥4）时最优
V8 图标按钮着色文字hairline 行极窄空间、熟练用户

建议基座：V1（均衡耐看）；文件 ≥4 自动切 V7 分组；1 个文件回落 V3。 V4 / V5 是「去彩化 vs 快扫读」的两个极端，看你的取舍。
