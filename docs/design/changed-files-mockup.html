设计说明

01数据从哪来

  • 工具调用结果天然携带 file_path，harness 按 messageId 聚合为 changedFiles[]
  • 确定性数据，模型零感知、零幻觉；模型回复文本只负责描述，不负责报路径

02聚合规则

  • 同文件多次编辑 → 合并一条，行数累加
  • op 推导：Write 且不存在 → 新建；SearchReplace / Edit → 修改；Delete → 删除
  • 行数统计由 harness 落盘前后 diff 得出，±N 为 Git 语义

03点击路由表

文件类型行为
.html / mockup预览面板 iframe 渲染（sandbox）
源码 / 文本只读查看，默认 Diff，可切原文
图片内置查看器
已删除仅 Diff，头部提示「已删除」

04方案取舍

  • A vs B：B 省高度但多文件时拥挤，A 为默认，B 仅在 ≤2 个修改时启用
  • 不采用弹窗确认：打断流式体验，危险操作才走审批流

05数据结构示意

消息负载附带，渲染层零猜测：
