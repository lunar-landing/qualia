选型说明

方案借用原子优势代价
N1 chips 行tool-chip 全套与工具调用条零违和，换行自适应预览箭头 hover 才出现，可发现性略降
N2 时间线act-flow 竖线+节点过程→产物叙事最连贯，op 色在节点上很自然纵向最高，长清单略空
N3 线框清单code-wrap 容器边界清晰、文件多时最整齐容器感最重，与「去气泡」稍有张力
N4 摘要行行内 mono 元信息最轻，几乎零占位op 只有字符，新用户需学习；多文件拥挤

建议：N1 为默认（与消息区现有胶囊语言完全一致，回归成本最低）；若希望突出「产物收尾」的仪式感选 N2； 文件经常 ≥4 个的场景选 N3。四案 op 色统一沿用产品语义色（写入=ok 绿 / 修改=琥珀 / 删除=err 红）， 仅 10px 小字使用，与 tool-chip 状态字同权重。
