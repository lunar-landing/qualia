现役降噪窗（对照）

14px 大圆角 + 红黄绿彩点 + 极淡底头。彩点是全应用唯一彩色装饰，圆角也超出 9~11px 体系，故显突兀。仅作对照，不参与选型。

typescript 
// 计算 token 用量的日聚合统计
export function aggregateDaily(stats: TokenStat[]): DailyUsage {
  const map = new Map<string, number>();
  for (const s of stats) {
    const day = s.timestamp.slice(0, 10);
    map.set(day, (map.get(day) ?? 0) + s.totalTokens);
  }
  return [...map.entries()]
    .sort(([a], [b]) => a.localeCompare(b))
    .map(([date, tokens]) => ({ date, tokens }));
}

哑窗式

保留一点窗体暗示但彻底灰阶化：无边框，头部 2.5% 极淡底 + 细分隔线，语言名前加一枚 $ 提示符代替圆点做终端隐喻。比 A 多一档层次，与侧栏/hover 面板同语言，安静但不寡淡。
