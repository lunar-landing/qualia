代码块重设计四个方向 · 深浅主题 · 复制按钮可点击

V1

线框式

头部无色块，仅一条细分隔线；语言名纯文字，复制按钮 hover 代码块才显现。最安静、最像 GitHub README，装饰归零。

typescript 
// 计算 token 用量的日聚合统计
export function aggregateDaily(stats: TokenStat[]): DailyUsage {
  const map = new Map<string, number>();
  for (const s of stats) {
    const day = s.timestamp.slice(0, 10);
    map.set(day, (map.get(day) ?? 0) + s.totalTokens);
  }
  return [...map.entries()]
    .sort(([a], [b]) => a.localeCompare(b))
    .map(([date, tokens]) => ({ date, tokens }));
}
V2

胶囊标签

骨架同 V1，但语言名做成灰底胶囊标签，头部加一层极淡底色。语言一眼可扫读，比 V1 多一档信息重量，日常耐看。

V3

悬浮无头

彻底去掉工具条：语言名 + 复制按钮收进右上角毛玻璃浮层，平时半透明、hover 显现。内容密度最高，视觉最干净；代价是浮层会轻微压住首行代码右端。

V4

降噪窗

保留终端窗的窗体感但全面减重：头部从色块降为极淡底、圆点缩小降饱和、语言名从居中改左置、圆角放大到 14px。是现役终端窗的柔和版，延续性最好。
