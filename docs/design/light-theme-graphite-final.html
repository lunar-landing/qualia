四处精修：边框统一 GitHub 实色 #d0d7de；你的气泡加深一档和白气泡拉开；输入框聚焦换成石墨描边 + 灰光圈；语义色用 GitHub 无障碍色。

① 边框升级

#d9dee4 → #d0d7de（GitHub 真实边框色）。所有描边清晰不虚，工程感的关键就在这条线的实度。

② 气泡对比

用户气泡 #eef1f4 → #e9edf2，与纯白 AI 气泡、侧边栏 #eff2f5 三层灰阶各自分明，不再糊在一起。

③ 聚焦态去彩

输入框聚焦从生产版的紫描边+紫光圈改为石墨描边 + 10% 灰光圈，日间模式全程无彩色装饰。

④ 语义色保留（功能色非装饰色）

● 成功 #1a7f37 ● 警告 #9a6700 ● 错误 #cf222e

采用 GitHub 无障碍语义色，仅用于状态反馈（工具成功/失败、任务状态），不参与装饰。
