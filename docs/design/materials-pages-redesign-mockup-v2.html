为什么这样改：上一版的问题在于元素太碎（彩色书脊 + 彩色图标 + 大写 mono 标签 + 渐变带），彼此抢视线且互相不成体系。这一版把视觉重量交给排版：24px 页面标题、14.5px/600 库名、12.5px 描述、11.5px 元信息，四级递减，卡片内部靠留白与一条极淡的分隔线分区，不再画任何框。
构成条是全卡唯一彩色：3px 高、按类型占比分段，色相取自文件类型但统一降饱和（--t-*），只作为数据可视化存在，不承担装饰；hover 时卡片浮起 2px，元信息尾部滑出强调色箭头。
操作只保留重命名 / 删除两枚，24px，hover 才出现；进入整卡可点，不重复设置按钮。「新建」按钮文案压成 新建（实心墨色，页面上唯一的实心块），描述为空时文案用 尚未填写描述 并降一级灰度。

分栏关系：左树栏白底、右内容区极浅冷灰底（--card-2），文章条目再用白底浮起——靠底色层级而不是边框区分区域，这是整页看起来"干净"的关键。
树：栏头只放库名（右栏 Hero 是同名重复，但首页需要一个可编辑的锚点，故保留）+ 三枚分组图标；层级缩进用 1px 左边线代替纯空隙，深树不至于散开；文件行不再放彩色图标（图标在树里是噪声，选中态已足够指认），选中行 = 强调色底洗 + 强调色文字 + 左缘 2px 竖条；转换中行只用一个旋转图标，不加底色。
首页结构：Hero（52px 描边图标块 + 25px 库名 + 描述 + 一行点分元信息 + 右缘操作）→ 最近编辑（高频入口置顶，紧凑单列）→ 分组文章（双列条目，标题 + 摘要一行 + 右侧等宽字数）。分组头用 11px 大写字距 + 计数 + 延展发丝线，替代原来的文件夹图标组头。
文章条目左侧 7px 圆角小方块标类型（唯一彩色，降饱和），比整枚彩色文件图标安静得多，且和构成条、列视图共用同一组色值。

工作台交互说明

源自 PRD 评审稿.docx LX林翔2026-10-211,240 字约 4 分钟

工作台由三栏构成：左侧会话列表、中间对话区、右侧资料面板。三栏均可独立收起，收起状态写入本地配置，跨会话保持。

三栏收起规则

每栏头部保留一枚 28px 收起按钮，收起后在相邻栏边缘出现 6px 悬浮导轨，悬停即展开预览、点击固定。

窄屏（<1200px）下右侧资料面板默认收起，避免对话区正文宽度低于 640px。
  • 宽度区间：左 200–320px、右 240–420px，拖拽边界即区间端点
  • 拖拽热区：4px 分隔线，命中后光标切换为 col-resize
  • 双击分隔线恢复默认宽度

阅读区排版

正文列最大宽度 672px，配合右栏 180px 目录整体居中；无目录时正文列保持同宽，切换文章不产生横向跳动。

相对现状的改动

  • 列表页：卡片去彩，类型信息压进底部 3px 构成条；新增搜索与排序
  • 列表页：另出一版列式清单，与卡片共用数据，做成视图切换
  • 空态：删掉三步流程，只留一句说明 + 新建 / 上传两个行动点
  • 详情页：右内容区改极浅灰底，条目白底浮起，用底色分层
  • 树：文件行去图标，选中态换强调色底洗 + 左缘竖条
  • 首页：Hero 去渐变去 chips → 描边图标块 + 点分元信息一行；新增「最近编辑」
  • 阅读：h2 去装饰条，正文降到 --ink-2，目录栏用左线串联
  • 编辑：行号极淡化 + 当前行强调色，Markdown 三档着色，状态栏小圆点示同步

风险

  • 构成条与类型小方块需要按类型统计占比，现有接口只给 articleCount / totalChars，要补 kindBreakdown
  • 「最近编辑」按文章 updatedAt 排序，前端可算，无需后端改动
  • 整体去彩后，若后续引入头像/封面图，需要重新约定彩色面积上限（当前 <3%）
  • 夜间模式换色值不换结构；--hair 在暗底需提到 6% 白才可见
