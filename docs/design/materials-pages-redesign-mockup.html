工作台交互说明

源自 PRD 评审稿.docx 2026-10-211,240 字约 4 分钟

工作台由三栏构成：左侧会话列表、中间对话区、右侧资料面板。三栏均可独立收起，收起状态写入本地配置，跨会话保持。

三栏收起规则

每栏头部保留一枚 28px 收起按钮，收起后在相邻栏边缘出现 6px 悬浮导轨，悬停即展开预览、点击固定。

窄屏（<1200px）下右侧资料面板默认收起，避免对话区正文宽度低于 640px。
  • 宽度区间：左 200–320px、右 240–420px，拖拽边界即区间端点
  • 拖拽热区：4px 分隔线，命中后光标切换 col-resize
  • 双击分隔线恢复默认宽度

阅读区排版

正文列最大宽度 700px，配合右栏 176px 目录整体居中；无目录时正文列保持同宽，切换文章不产生横向跳动。

const readerGrid = 'minmax(0,700px) 176px'
justifyContent: 'center'

代码块超过 40 行时折叠，展开按钮固定在块底缘，避免长代码把正文推出视野。

相对现状的关键改动

  • A 卡片网格 → 书架行式（色带书脊 + 类型构成徽标 + 右对齐等宽元信息）
  • A 新增列表搜索框与排序，头部加总量汇总
  • A0 空态纵向步骤文字 → 横向胶囊步骤条；弹窗字段标签大写字距化
  • B 树栏头改用 mono 标签「CONTENTS」，库名不再重复
  • B Hero + chips → 渐变封面带 + 四格统计条
  • B 文章卡加 mono 序号，分组头大写字距化
  • B 阅读 h2 加墨线短标，TOC sticky + 当前项高亮
  • B 编辑加行号栏、语法轻着色、状态栏与快捷键提示

风险与取舍

  • 行式列表在库数很多（>30）时纵向偏长，可保留网格作为可切换视图
  • 封面带四格统计需后端补 formats 字段（类型种数），否则改显示首字母类型分布
  • 序号依赖前端渲染顺序计算，与过滤/分组重排联动需注意编号语义仅为视觉锚
  • 书脊取主类型色：混合库以占比最高者着色，空库用 --text-3 灰
