资料库侧边栏 · 三版本设计

264px 文章树栏 · 石墨变量 · 日间默认

三个版本的过滤框均可真实输入（试试「部署」或「spec」），文件夹可点击折叠；选中行统一带 左缘竖条，滚动跟随与折叠记忆为行为项不在视觉稿内。推荐 V1。

V1 · 静默精修推荐 现状布局上的增量优化
设计点
  • 树头下嵌 32px 紧凑过滤框：输入即过滤，命中文章自动展开祖先链
  • 树头按钮分组：新建类（文件夹/文章）与上传之间细分隔线，语义分堆
  • 选中行左缘 2px 墨色竖条 + bg-active，与 hover 拉开层次
  • 文件夹展开态切换 fa-folder-open，开合有直接反馈
  • 行高/密度/信息结构完全不动 —— 风险最小
V2 · 双段头 上传提为文字主按钮
设计点
  • 树头两段式：第一行库名 + 实底「上传」主按钮（最高频动作给最高权重）
  • 第二行 38px 大过滤框，视觉上一级入口；Esc 清空
  • 新建文件夹/文章收敛为过滤行右侧的「+」下拉（结构让位给过滤）
  • 取舍：头部多占一行高度；实底按钮是全栏唯一重色，注意力锚点明确
V3 · IDE 密度 紧凑行 + 文章数徽标
设计点
  • 行高 40→34px、间距减半、字号 12px：同屏多显约 15% 条目
  • 文件夹行右侧文章数徽标（mono 圆角块），结构一目了然
  • 字数弱化为 muted 色——名称是主信息，元信息退后
  • 取舍：密度接近 IDE 文件树，但与产品其余 40px 行节奏有落差
共同基线：40px 树行（V3 除外）· hover 让位行内操作（打开/重命名/删除）· 空文件夹弱化行 · 过滤为纯前端本地计算，零接口。
行为项（不在视觉稿）：过滤命中自动滚动到首个命中行 · 选中行 scrollIntoView 跟随 · 折叠状态按「库 + 路径」记忆于 store。
