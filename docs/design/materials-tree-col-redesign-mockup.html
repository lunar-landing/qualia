资料库 · 文章树栏（kb-tree-col）重设计

264px 定宽栏 · 头部动作收纳 / 过滤形态 / 行密度 / 选中态

现状：树头一行塞满「库名 + 新建文件夹 / 新建文章 / 上传」三个图标钮，过滤框常驻占高，行高 40px、选中仅整行铺底。以下四版从结构层面重新分配这些信息。文件图标沿用真实类型配色（PDF 红 / Word 蓝 / MD 靛 / HTML 橙），选中态统一改为「左 2px accent 竖条 + 浅底」。
