新建资料库
库名用于对话中的检索指称（如「查一下产品文档」），创建后可修改。
空态规格（P9，三处空态同语言：列表空 / 库空 / 树空）：64px 大图标块（radius 18，bg-blockquote 底 + accent 图标）→ 15px/600 标题 → 编号步骤（18px 圆点序号 + 加粗动作 + 说明）→ 实底主 CTA 上移至步骤下方 → 11px muted 副提示收尾。 相比现状：去掉纯文字 fa-1/2/3 步骤行，主 CTA 从页头「重复可达」改为空态主视区直接给行动点。 弹窗：380px 宽 · radius 16 · pad 18/20，标题 + 一句用途说明（新增）+ 名称 / 描述两字段，底缘右对齐「取消 / 创建」；遮罩 rgba(0,0,0,.35)。Enter 提交、Esc 关闭、名称为空时禁用提交。删除库走同规格确认弹窗（见 G）。
