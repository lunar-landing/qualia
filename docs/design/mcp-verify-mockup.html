MCP 管理 UI 设计稿 — 弹窗编辑模式
qualia-claw 侧边栏 MCP 管理面板。卡片改为只读展示，编辑操作通过弹窗完成。跟随系统深色/浅色主题。
交互流程
1. 卡片只读展示：名称、传输方式、服务地址、验证状态，不提供内联编辑
2. 点击卡片上的 编辑 按钮 → 弹出编辑弹窗，弹窗内包含所有可编辑字段 + 验证连接按钮
3. 弹窗底部 验证连接：点击后按钮变加载态，结果展现在弹窗内（不影响列表视图）
4. 验证通过后点击 保存 → 关闭弹窗 → 卡片列表刷新
5. 点击 取消 或遮罩 → 关闭弹窗，不保存
6. 验证结果在弹窗内有效，关闭弹窗后清除；卡片上的状态徽章记录上次验证结果

后端 API 设计
POST /api/mcp/verify

Request Body（弹窗内直接传入表单值，不依赖已保存配置）：
{
  "name": "notion-mcp",
  "transport": "streamable-http",
  "url": "http://localhost:3001/mcp",
  "headers": { "Authorization": "Bearer xxx" }
}

Response — 成功：
{
  "success": true,
  "serverName": "Notion MCP Server v2.1.0",
  "latencyMs": 126,
  "toolCount": 8,
  "toolNames": ["query_database", "create_page", ...]
}

Response — 失败：
{
  "success": false,
  "errorType": "连接超时",
  "errorMessage": "Connect timed out (10s)"
}

备注：用户可以在弹窗内先改字段再验证再保存，无需先保存再验证。
验证结果在弹窗关闭后清除，卡片状态徽章记录最近一次验证结论。
