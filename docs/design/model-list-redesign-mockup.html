M1 行式列表 · 密度与一致性优先

与 MCP Tab 行式表单、设置弹窗整体基因最统一；按钮 hover 浮出后视觉噪音最低。默认用「竖条 + 反色徽章」表达。改动小（仅重写 models Tab 模板与样式），编辑子弹窗完全不动。

M2 卡片精修 · 迁移成本最低

骨架不变，只重排信息层级（模型 ID 升主视觉）+ 默认顶边条 + 操作滑出。卡片在模型数 ≤ 8 时观感最好；baseUrl 为新增展示字段（现卡片未展示）。

M3 厂商分组 · 多模型友好

radio 直切默认省去「编辑 → 设为默认」两步；组头数量与星标提供结构感。模型都不同厂商时分组头略冗余（每组 1 条），分组价值随同厂商模型数增长。

M4 数据表 · 扫读效率最高

六列一屏全字段对比，radio 直切 + 图标操作；代价是单行截断、无次要信息（baseUrl 需进编辑看），移动端窄弹窗下需要降级为行式。

M5 双列卡片 · 弹窗内统一

与工具 Tab 已落地的 T2 双列卡片同规格（白卡 / 圆角 / 边框 / hover 反应 / mono 主文案）， 默认 徽章与工具 停用 徽章互为镜像（accent 反色 vs 琥珀）。整个「扩展」分组观感一致；模型数少时双列比 M2 的自适应网格更稳定不空心。

M6 主从式 · 信息最全

唯一能把 baseUrl 等编辑态字段直接摆出来的方案；代价是交互模式变化（点击 = 选中而非进编辑），需新增 selected 状态。模型数多时列表 + 详情双区不拥挤；模型只有 2-3 个时右栏略空。

M7 层级式 · 主次分明

「当前默认」大卡 + 备选行 radio 直切；把「默认」从徽章升为结构（置顶大卡），切换心智最清晰。模型增多时备选区自然滚动，主卡始终可见。

M8 胶囊墙 · 最轻

一屏可容纳 10+ 胶囊；悬浮菜单复用现有规范（Teleport 定位 / 外点关闭）。信息量最少（Key 状态只留「未配 Key」提示），适合模型数多且配置稳定的场景。

通用约束

能力集不变：点击行 / 卡仍进编辑子弹窗、默认唯一、Key 掩码、草稿式保存；配色零新增（日间浅灰弹窗底 + 白卡片层次已落地）；厂商渐变 dot 延续；M2 之外的方案均可把「设为默认」并入 radio/徽章。

选型建议

与设置弹窗整体一致性最好选 M1；改动最小选 M2；预判单厂商多模型选 M3；重扫读效率、模型字段对比选 M4；要求与工具 Tab 观感统一选 M5；模型配置复杂、想直接看 baseUrl 选 M6；强调当前生效 / 切换心智选 M7；模型多且轻管理选 M8。M1 与 M4 可互为窄宽度降级形态。
