待发送队列 · 输入框顶部展示 · 多方案对比

排队消息收敛到输入框顶部列表，消息流只保留已发送内容（发送即离开列表）。三个版本同一场景：生成中 + 2 条排队。

版本 形态 静态占高 信息量 交互步数 取舍
V1 紧凑行式推荐 每条单行：序号 + 截断文本 + 删除 ≈ 34px / 条 低（完整文本靠悬停 title） 1 步（删除直点） 最轻、与输入区融合最好；长消息需悬停看全文
V2 预览卡片式 每条两行卡片：徽标 + 正文预览 + 附件 chip ≈ 62px / 条 高（正文前两行 + 附件） 1 步 长消息、带附件场景最稳；列表长时占屏明显
V3 折叠摘要式 默认一行「队列 n 条」，展开看完整列表 ≈ 30px（折叠） 默认零，展开后同 V1 2 步（展开 + 操作） 最省空间；多一层交互，队列状态可见性弱

共用规则（三版本一致）：列表超过 4 条时内部滚动（max-height）；顺序即入队顺序，不支持拖拽排序； 发送中的条目从列表移除并进入消息流；错误 / 停止后列表保留，头部出现「立即发送 / 清空」。
