定时任务卡片 · 重设计对比

信息结构重新组织（不同于此前只换皮肤的四变体稿）：现状的问题是「上次/下次」两行定宽时间列占位过重、状态靠 13px 小点、meta 与时间列语义粘连。 每款展示典型状态：执行中 / 正常 / 最近失败 / 已暂停。
V0

现状基线（对照）

状态点 + meta 子行 + 右侧两行定宽时间列（156px）。问题：时间列内容短、占位重，扫视动线在「两行时间」上停留过久。

V1

meta 合并 · 下次唯一主信息

推荐

「上次运行（相对时间 + 成败）」降为 meta 的一项；右侧只留「下次」且升为主信息：相对倒计时大字 + 绝对时间小字。左缘 3px 圆头色带接替状态点，卡内元素从 5 组减到 3 组。

V2

执行脉搏

右侧时间列整体替换为最近 10 次执行的色块条（GitHub Actions 语言）：绿=成功、红=失败、蓝闪=执行中、灰=顺延跳过；块高映射耗时。下次触发压成 meta 尾部一行小字。

V3

三段分层 · pill 化 meta

卡片重构为「标题 / meta pills / 底栏」三段：提示词放宽为可换行主标题（2 行截断），周期、状态、上次运行全部 pill 化，底栏浅底收「下次运行 + 操作」。

V4

紧凑单行

去卡片化：一行一任务，分割线分组，左缘色带承状态；周期 / 上次 / 下次定宽列对齐，hover 行底色浮现。密度约为现状 2 倍，像 crontab 管理台。

G3
