定时任务 · 界面设计

定时任务 = 问答 + 周期属性。四个落位：侧边栏「任务中心」（全局管理 + 执行历史）→ 输入区「定时」（创建：写好提示词选周期即建任务）→ 会话头部 chip（就地管理）→ 执行轮次徽标 + 摘要行（结果直观可见）。先看区块 0 的全局落位图。

原则：用户写的仍是一条普通消息，只是发送前多选了一个周期；管理与状态都留在会话现场，设置弹窗不加 Tab。 视觉：延续队列 v3 语言——纯文字 + 淡细线 + 悬停显隐；定时条激活时发送按钮转绿、placeholder 同步变化。
