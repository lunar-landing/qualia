A分组时间线 推荐 · 默认

项目组为一级结构（沙箱组置顶），组内按时间倒序、行尾给相对时间补回时间维度。组头即「项目上下文」：名称 + 条数 + 悬停 ＋。

  • qualia4
  • 重构 WorkspaceHistory13:07

  • 会话存储迁移验证周二
  • demo-app2
  • 联调登录接口昨天
  • 首页视觉走查9/30

规则

  • 组序：◇ 沙箱组恒置顶 → 项目组按组内最近活跃倒序
  • 行尾时间：今天显示 HH:mm，更早显示「昨天 / 周X / M/D」，10px 弱化
  • 组头悬停 ＋：新建并绑定该项目的新会话；沙箱组 ＋ = 新建默认会话
  • 搜索时组头隐藏、命中行平铺（命中唯一上下文就是标题高亮）

优点 / 代价

  • ＋ 归属一屏全览，与「绑定是会话属性」的语义完全同构；改动集中在 rows computed 的分组键
  • － 项目多 + 会话多时列表变长（时间维度弱化为行尾小字）

适用：默认形态；会话量中等、项目 2~10 个的日常场景。

规则（在 A 之上追加）

  • 组头 = 折叠开关（chevron 旋转 0.2s）；折叠态仅留「图标 + 名称 + 条数」一行
  • 折叠状态 localStorage 持久化（key 按工作区路径）
  • 例外：活跃会话 / 产生未读的组强制展开，折叠不可作用于它
  • 组头悬停仍出 ＋（与折叠互不干扰：chevron 在左、＋ 在右）

优点 / 代价

  • ＋ 大量会话时可把不活跃项目收起，扫读噪音最低化；IDE 用户零学习
  • － 多一层状态（折叠持久化 + 活跃组强制展开的边界）；「收起后忘了里面有未读」需条数/绿点补偿

适用：会话量大（50+）或多项目重度用户；可作为 A 的无破坏增强（组头加 chevron 即可，分阶段上线）。

C工作区筛选器 时间轴优先

不改变列表结构：顶部加一条工作区 chip 筛选条，「全部」= 传统日期分组流 + 行尾归属徽标；选中某工作区 = 同样的日期流但只含该工作区。可点击 chip 体验。

    规则

    • chip 条为临时视图过滤，不是状态切换：不持久化、无「当前工作区」语义（重启回「全部」）
    • 「全部」视图行尾带归属徽标（色点 + 项目名）；筛选后徽标隐去（上下文已明确）
    • 日期分组（今天 / 昨天 / 近 7 天 / 更早）完整保留——与现状 sessionGroupLabel 完全同源
    • chip 条末尾固定一枚 ＋：新建会话并绑定到当前选中工作区（「全部」时=新建默认会话）

    优点 / 代价

    • ＋ 时间轴体验与现状零差异，实现面最小（一层 filter）；筛选是显式动作，不与绑定语义混淆
    • － 归属一屏不可见，项目全貌要靠切 chip；多一层「筛选态」心智（但它是视图态而非数据态）

    适用：用户以「最近在做什么」为主轴找会话、项目上下文其次；或作为 A/B 之上的叠加能力（chip 条与分组可并存：分组内再筛）。

    D扁平时间流 + 归属徽标 不推荐 · 列出供对比

    • 徽标色（蓝灰调）：沙箱 = 虚线 ◇ 灰蓝，项目 = 各自固定色点（按项目名 hash 取色）

    优点 / 代价

    • ＋ 结构与现状完全一致，视觉最安静
    • － 「项目下新建」失去自然落点，需另造入口；找某项目的会话只能靠扫徽标或搜索——与「多项目历史库」定位相悖

    适用：几乎不用项目功能的轻度用户。列出仅供对比，不建议作为默认。

    07选型建议

    以「归属扫读优先、时间扫读其次」为默认权衡。

    默认落 A（分组时间线）——与绑定语义同构、改动收敛在 ConversationList.rows 分组键 + 行尾时间；B 作为第二阶段增强（组头加 chevron + 持久化，接口不变）；C 的 chip 条可与 A 叠加（先分组、组内再筛），留作后续按需；D 淘汰。若你更看重时间轴原体验，改选 C 亦可，代价是项目全貌需切换查看。
