推荐

实现：现有 streaming-dot / unread-dot 直接换 var(--success) 并改为角标定位，改动最小。

方案 B · 琥珀工作 × 蓝未读

双色双语义：琥珀 = 正在工作（暖色进行时），蓝 = 有未读产出（IM 惯例）。 状态区分度最高，一眼分辨「在跑」和「跑完了」。代价：引入两个新色相，页面彩色面积增加。
色相取自蓝灰调色相带的暖/冷两端，与主界面不冲突。

方案 C · 微型 Spinner × 冷雾蓝

生成中：图标位整体替换为 12px 旋转弧线——「正在处理」的表达最直白，工具感强（IDE / CI 风格）。 未读：冷雾蓝静态点。动态与静态形态差异大，弱光下辨识度也高。
