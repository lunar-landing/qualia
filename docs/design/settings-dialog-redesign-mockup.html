现有骨架逐项升级：导航双行化（描述辅助识别）、节标题行、 1040px 三列卡片、底部保存栏（未保存更改琥珀点 + 主按钮右置）。 现有交互（点击卡片弹编辑、hover 操作浮层）全部保留，迁移成本最低。

D2 IDE 设置风 · 工程感优先

D1 全部能力 + 头部搜索（设置项过滤 + ⌘K ）、导航分组（服务 / 扩展）与数量徽章、表单横向行式。 设置项继续增多时导航可再分组，扩展性最好。

D3 现代卡片风 · 视觉优先

去左导航改顶部分段控件，全宽内容、横排行式列表、 底部浮动保存胶囊。最现代，但导航重写、编辑子弹窗建议改行内展开，改动最大。

通用约束

宽度统一 min(1040px, 100vw − 48px) （代码已生效）；配色零新增（全部映射现有 app 变量）； 厂商渐变 dot、毛玻璃、默认徽标语言延续现状；能力集不变 （模型 / MCP / 技能 / 工具 + 草稿式保存）。

选型建议

求稳选 D1；预判设置项增长（如后续加外观 / 会话设置）选 D2； 追求观感焕新且接受较大改动选 D3。D1 → D2 可渐进演进（先 D1 后加搜索与分组）。
