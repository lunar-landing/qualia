横向对比

样式项目识别方式总览能力运行中可见性侧栏宽度改造量适用
S1 分组手风琴组头分组展开即全览组头 spinner不变最小默认形态，P1 落地
S2 色轨脉搏流左缘色轨 + chips混排即全览行内流光晕不变小项目 ≤ 5、重「最近动态」
S3 双列项目轨字母块轨道弱（靠聚合入口）轨道角标+48px中项目多、桌面宽屏
S4 焦点优先流行内小徽章运行区 + 平铺流置顶区最强不变中多项目同时跑任务
S5 堆叠切换器下拉预览聚合面板下拉绿点不变最小共存能力首发交付
建议路径：以 S5 起步（一个下拉 + 一个聚合面板，当天可交付）→ S1 转正为常驻形态（手风琴分组）→ 有多项目并行需求后叠加 S4 的「运行中」置顶区（S1+S4 天然兼容：置顶区插在分组列表上方）。S2 适合项目少、以「动态」为中心的用户，可作为 S1 的显示模式开关（分组 / 混排二态）。S3 留给桌面端宽屏场景。五种样式共用 /sessions/all 一份数据，切换成本仅在 ConversationList 渲染层。
