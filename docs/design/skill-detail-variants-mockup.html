Overview

本技能提供 PDF 处理全套脚本：文本提取、分页拆分、表单填写。所有脚本基于 pdfplumber，输出统一为 UTF-8。

Usage

bashscript/extract_text.py
python script/extract_text.py "input.pdf" --pages 1-3

Troubleshooting

扫描版 PDF 无文本层时需先 OCR，脚本不内置识别。

结构要点
  • 左栏 216px sticky 三组：小节 TOC（滚动跟随高亮）/ 脚本 / 附属文档
  • 正文单卡铺满剩余宽度，不留左右边距

优点

  • 附属文档可就地阅读，无需离开页面
风险点
  • 需要后端补 TOC 与文档正文接口（现仅返回文件名）
  • 脚本 ≤2、正文 ≤40 行的技能，左栏明显空
  • 窄窗口下正文列被压到 600px 以下

Overview

本技能提供 PDF 处理全套脚本：文本提取、分页拆分、表单填写。所有脚本基于 pdfplumber，输出统一为 UTF-8。

  • 提取纯文本与表格：extract_text.py
  • 填充 AcroForm 表单字段：fill_form.py

Usage

bashscript/extract_text.py
python script/extract_text.py "input.pdf" --pages 1-3
结构要点
  • 分段控件沿用页头 .kv-seg 凹槽样式，视觉零新语言
  • 概览 tab 承载版本 / license / 目录 / 脚本 / 文档计数表
  • SKILL.md 与各类文件各占一个 tab，互不打扰
优点
  • 页面最精简，任何一类资源都一击可达
  • 后续加「变更记录」「使用统计」有现成位置
风险点
  • 主要阅读物 SKILL.md 变成 tab 之一，进入页面默认停在哪需要再定
  • tab 与列表页的分段（已安装 / 市场）语义重复，易混淆
