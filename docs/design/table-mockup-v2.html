通用优化点（A-J 全部包含）：① 表头去 uppercase 与浅底（中文表头下 uppercase 无意义，浅底是现状观感偏重的主因）；② 单元格字号统一 12.5px，与代码块一致，避免表格比正文抢眼；③ 单元格 white-space: nowrap + 表级 overflow-x: auto——宽表横向滚动而非挤压换行（修掉现状行高失衡问题）；④ 保留 width: fit-content（D / E 为满宽除外）；⑤ 行内 code 沿用气泡现有内联代码样式。
