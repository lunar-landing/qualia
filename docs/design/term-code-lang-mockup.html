CL1

角标 chip

右上角悬浮小标签，不占代码行：chip 式（bg 底 + 1px 线），hover 代码块时点亮为绿。信息清晰、零侵入；缺点是浮在代码上方，长行会从标签下穿过。
python 
def summarize(rows):
    # 按得分倒序取前三
    top = sorted(rows, key=lambda r: r["score"], reverse=True)[:3]
    lines = [r["name"] for r in top]
    return "\n".join(lines)

CL3

命令前缀式（$ python）

语言名当「命令」展示：`$ python`，$ 用终端提示符绿。与输入区 REPL prompt、消息区 `$ 命令行` 完全同一叙事——「这段代码是 python 写的」，终端感最强。
