H1

启动日志（boot sequence）

模拟 CLI 工具启动自检：`$ qualia-code` + 绿 ✓ 检查行（工作区 / 模型 / 工具 / 会话），随后 tagline 与建议。信息真实可用、逐行淡入，像工具每次启动打印的横幅——终端原生感最强。

H2

neofetch 信息卡

左侧单个品牌符号（垂直居中）+ 右侧环境键值（workspace / model / tools / sessions）：neofetch 式「系统信息卡」。neofetch 原版的左栏是整块大 logo，这里收敛为单颗四角星火花（与聊天模式 hero-logo 同源）；品牌与真实环境信息同屏，极客辨识度最高。

H4

虚拟终端窗

整块 hero 就是一扇终端窗口：标题栏（熄灭三点 + `qualia-code — session`）+ 窗内品牌行 / tagline / 建议 / 末行 PS1 待命光标。滚动进入会话时窗体可整体淡出，舞台感强。

H5

路径横幅（你在这里）

大号真实工作区路径当主标题：`~/Projects/qualia` + 待命 prompt（❯ + 闪烁光标），下接 tagline 与建议。「你在这里」的定位感最强，路径随工作区切换自动变化。
