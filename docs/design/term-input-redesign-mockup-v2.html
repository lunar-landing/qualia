A 双行控制台 · 连续性优先

现状直接瘦身：删头栏，其余不动。soft 底栏保留结构感，模型 pill 仍在底栏右。 改动成本最低（删 tc-head 一个节点 + 微调间距）。

B 裸行轻量 · 极简优先

去 soft 背景与边线，meta 全部文本化为一行， + 附件 │ --model ▾ │ ⏎ 。输入区完全融入会话流，最像真终端；无实体按钮，纯文本 hover 点击。

C 顶置工具行 · 结构反转

meta 上移输入行上方（模型左 / 附件右），底部零残留；运行态占用工具行。 输入行上下无夹层，最干净；与 IDE 输入框心智一致。

通用约束

配色零新增（全部 --t-* 映射）；能力集不变 （附件 / 模型切换 / 发送 / 停止）；运行中一律 spinner + 红色停止路径； 附件 chips 语言三案统一（⌗ name ×）。

选型建议

保结构、低成本选 A；要极简终端感选 B；要输入行最干净、 接受 meta 在上方选 C。可组合：C 的工具行 + A 的 soft 背景条。
