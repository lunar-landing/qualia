V1 盒式精修 · 连续性优先

在现有 .term-input 上叠加：聚焦光环（accent 3px 外环）、附件 chips、右下角实体按钮。 键帽与按钮并存，键鼠双路径。改动成本最低。

V2 裸行 CLI · 极简优先

零盒子零背景，仅一条渐隐分隔线；所有操作退化为快捷键与行内文本。 ⏎ esc + 最像真终端，但无鼠标路径、附件管理较弱。

V3 控制台面板 · 结构优先

头栏（会话上下文 + 模型 pill 可点开切换）/ 输入 / 底栏（附件 + 行动按钮）三段式。 信息架构最完整，模型选择从只读升级为可切换的入口。

V4 tmux 状态条 · 密度优先

输入行保持单行纯粹，元信息全部下沉状态条分段展示；运行态以琥珀色 seg 强调。 工程感最强，小屏时状态条可按优先级截断。

通用约束

配色零新增（全部 --t-* 映射）；能力集不变（附件 / 模型 / 发送 / 停止）； 运行中一律 spinner + 红色停止路径；光标为闪烁方块。

选型建议

追求「像真终端」选 V2；要鼠标路径与最低成本选 V1；想让模型选择可交互选 V3； 追求信息密度与工程感选 V4。可组合（如 V1 的按钮 + V4 的状态条）。
