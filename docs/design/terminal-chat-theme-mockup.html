消息 → 日志行

用户气泡退化为 ❯ 前缀行，助手回答为无气泡正文。 去掉头像、圆角卡片与分离式时间戳（时间右对齐同行为暗色小字），纵向密度约提升 40%，滚动浏览长会话更接近读 log。

步骤 / 工具 → 命令执行行

现有 ToolChip 映射为 $ cmd + [ok]/[err] 状态行（含耗时 / 行数 / +− diff 量）；展开详情对齐现有 ChipDetail，交互仍是点击展开。运行态用 braille spinner + […]。

思考过程 → :: 暗色斜体行

act-thought 以 :: 前缀暗色斜体呈现；完成后折叠为 ▸ 思考过程 · n 段，对齐现有 think-toggle 的收起行为。

输入区 → REPL prompt

保留现有能力（附件 / 模型选择 / 发送与停止），全部键帽化： ⏎ 发送 tab 补全 esc 停止 ，模型态显示为 --model xxx。流式光标用闪烁方块。

范围：仅聊天区域

本稿只覆盖 ChatArea（会话流 + 输入区）。侧边栏（SidebarArea）、工作区面板（WorkspacePanel）、 顶栏与状态栏维持现有 UI 不动，主题以「视图模式」并存切换，工具调用输出仍可联动右侧面板。

配色零新增

夜间/日间 = 现有暗/亮两套主题 --terminal-bg/-text/-prompt/-success/-idle 的直接映射，无新增配色；正文只新增一个等宽字体栈与少量排版类，无新依赖。
