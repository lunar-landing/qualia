T1 行式精修 · 稳

纯视觉升级，交互零变化：组容器化（与 M3/MCP 卡同语言）、 emoji → 双字母 mono 块 （跨平台渲染一致，不再受系统 emoji 字体影响）、去状态冗余文字。改动集中在 models Tab 同级模板与 TOOL_ICONS 常量。

T2 双列卡片 · 扫读

整卡可点切换 + toggle 双通道；停用卡降透明 + 「停用」小徽章。双列在工具数 15+ 时优势明显；窄弹窗需降级单列（grid auto-fit 可平移）。

T3 权限清单 · 管理效率

组级「全部启用 / 停用」是唯一的能力增量（批量写 disabledTools 草稿，仍走统一保存）；行高压缩 1/3，去图标后 mono 名称即身份。视觉最素，操作最快。

通用约束

三方案均保留底部「关于工具」说明条（升级为卡片式 info 条）；toggle 开关、草稿式保存、导航数量徽章逻辑不动；双字母图标块需维护 TOOL_ICONS 映射（emoji → 双字母），后续新工具加映射即可。

选型建议

求稳选 T1（推荐：与已落地 D2/M3 基因最连贯，改动最小）；工具会持续增多选 T2；把工具当权限表频繁调整选 T3。T1 与 T3 可叠加（T1 容器 + T3 组级开关）。
