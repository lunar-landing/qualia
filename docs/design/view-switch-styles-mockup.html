view-switch 样式优化 MATERIALS · READER HEAD · 4 VARIANTS
DESIGN NOTES · 设计说明

现状为「1px 边框容器 + 按钮间 1px 分隔线」的细线拼接分段，三重线条视觉碎，激活态 （中性底）与 hover 层级接近、辨识弱，且与设置页技能切换（独立胶囊）语言不统一。 以下四版均在真实 reader-head 语境中呈现，可直接点击切换体验状态；右上角可切日/夜主题。

V1凹槽分段 Inset Segmented 零 JS · 推荐
产品文档 fastjson 升级可行性评估
差异保留分段语义，去分隔线：轨道内衬 2px，激活项以白卡浮起（阴影 + 圆角），线条减为容器 1 条
风险夜间下浮起卡需控制透明度（已用 rgba 弱化）；暗色阴影存在感低，激活辨识略弱于日间
实现纯 CSS，改造量最小：现结构加 padding + 去 button 分隔线即可
V2滑块分段 Sliding Thumb 需少量 JS
产品文档 fastjson 升级可行性评估
差异同 V1 轨道语言，激活块以滑块位移动效迁移，状态变化反馈最直观
风险滑块定位需 JS（offsetLeft/width）；按钮宽度不等时需动态计算，Vue 中可封装为 15 行小指令
实现CSS transition + 一个监听 click 的定位函数；键盘可达性需补 focus 态
V3下划线指示 Underline Tabs 最轻量
产品文档 fastjson 升级可行性评估
差异去框去底，仅文字加粗 + 2px 下划线（accent 墨色），与面包屑同一基线，头部最安静
风险可点击区域小（需补 padding 命中区）；无容器包裹，密集工具栏中指示强度最弱
实现纯 CSS（::after scaleX 过渡），改动量与 V1 相当
V4墨色胶囊 Ink Pills 与设置页统一
产品文档 fastjson 升级可行性评估
差异独立胶囊 + 实心墨色激活（--accent 底 / --accent-ink 字），与设置页技能切换完全同语言（本卡顺带演示「原件/文本」对）
风险视觉重量最重：头部同时有实心激活胶囊 + 主操作按钮时易打架；胶囊间无线条关联，分段语义弱于 V1/V2
实现纯 CSS；若与设置页 .sv-btn 抽公共类可一并统一
