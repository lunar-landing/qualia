PRD v2 需求范围
转换自 PRD-v2.pdf user 上传 更新于今天 14:32 1.2 万字 · 约 25 分钟

本文界定 v2 版本的功能边界。阅读顺序建议：先看功能清单了解全量功能点，再回到本文细读各模块的范围定义。

范围原则：v2 只做「多会话并存 + 附件通道 + 权限模型」三件事，其余一律进 backlog。

需求背景

v1 为单工作区单会话模型，用户在多项目并行时需要反复切换工作区，上下文无法保留。v2 引入项目与会话的二元模型，会话可绑定项目，也可作为独立沙箱存在。

范围定义

多会话并存

  • 会话与项目解耦：绑定 → 项目根为权威工作区；未绑定 → 派生沙箱
  • 会话存储按 key 隔离，互不可见

附件通道

  • 图片直传视觉模型；文档解析正文以文字注入
  • 支持 pdf / docx / md / txt，解析器与资料共用

权限模型

档位文件修改命令执行
只读问答禁止禁止
确认后执行确认闸门确认闸门
自动执行允许允许

非目标

以下内容明确不在 v2 范围：多人协作、云端同步、移动端。详见1012 例会纪要的风险项讨论。

里程碑

M1 后端存储与解析管线 → M2 前端视图 → M3 会话集成 → M4 增强。排期以功能清单完成度为准。

milestones:
  - M1: backend-storage     # 存储 + 解析管线
  - M2: frontend-view       # 资料 / 附件视图
  - M3: session-integration # 会话引用与工具化
  - M4: enhancement         # 混合检索 / 库导读（另立项）
