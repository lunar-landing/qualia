Qualia Code · 前端变化效果稿 · 2026-10-07

会话绑定工作区 · 前端变化

启动不再强制选工作区；会话默认派生（免绑定直聊），绑定动作收进输入框的工作区按钮；
右上角实时显示当前会话的绑定；侧栏会话按归属分组。

变化点总览

位置现状实施后
启动未选工作区强制弹出全屏选择弹窗，选完才能用直接进入聊天（派生态），选择工作区延后到输入框按需触发
输入框无工作区入口新增工具行左侧「工作区按钮」：派生态显示 绑定工作区（虚线），绑定后显示 项目名；点击弹最近列表选择
右上角无绑定标识新增绑定 chip：派生 = 默认工作区（虚线徽标）；绑定 = 项目名 · 路径；点击可换绑 / 解绑
侧栏会话跟随当前工作区切换，单列表全局列表按归属分组：默认工作区组置顶 + 各项目分组
变化一 · 启动行为 旧 vs 新
左：现状——首次启动被弹窗阻断；右：实施后——直接进入聊天，会话即派生态，绑定动作延后。
