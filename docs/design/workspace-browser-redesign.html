设计说明

元素行为实现路径
地址栏文件模式 = mono 路径面包屑（工作区 › 目录 › 文件，末段加粗、长路径中段省略）；网页模式 = URL 截断显示纯前端，路径来自 preview 打开时携带的 path
刷新文件模式重新拉取内容重挂 srcdoc；网页模式 iframe reload零后端（preview store 内容重设 + seq 联动已有）
在文件夹中打开系统文件管理器打开并选中该文件新增 /api/config/file/reveal，平移现有 skills/{name}/reveal 的 explorer.exe 逻辑（/select 定位）
系统浏览器打开新窗口打开原始文件window.open(rawFileUrl(path))，零后端
复制路径剪贴板写入完整路径 + toast 轻提示纯前端
沙箱脚注10px 提示「相对路径引用的本地资源不加载」纯前端，仅文件模式显示

落地注意：preview store 需从「只存 html/url」扩展为携带 { kind: 'file' | 'url', path?, url }， 地址栏与按钮可见性由 kind 驱动；现有代码块预览（openHtml 无文件语义）地址栏显示「内联预览」占位或隐藏工具栏。
