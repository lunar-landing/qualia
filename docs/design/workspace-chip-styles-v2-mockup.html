工作区 chip 两态样式 · v2 三版

回归黑白灰工程审美：无语义色、无徽章、无斜体。三版语言：D 分段开关（交互感）· E 首字母方块（GitHub 风）· F 等宽路径（终端审美）。交互不变：点击弹下拉，锁定只读。

方案 D 二态分段开关 「沙箱 / 项目」肉眼可见的可切换
chip 做成微型二态 segmented：当前态近黑实底、另一态灰字常驻——「这里可以切」不再需要学习。

设计要点
  • 两段常驻：active 段近黑实底白字，非 active 段灰字
  • 沙箱态右段显示「选择项目」（点击入口暗示）；绑定态右段即项目名
  • 锁定态：整体 55% 透明 + 行尾小锁
优劣
  • ＋ 「可切换」的暗示最直白，无需悬停发现
  • ＋ 与发送按钮同体系（近黑 accent），黑白灰零新色
  • － 工具行里最宽的形态；项目名过长需截断
方案 E 项目首字母方块 GitHub 风 avatar · 识别度最高
绑定态 = 近黑小方块内项目首字母（项目 avatar），沙箱态 = 虚线空槽「+」。一瞥即知当前在哪个项目。

设计要点
  • 方块 17px / 圆角 5px / 近黑底白字首字母（mono 9px bold）
  • 沙箱态：同尺寸虚线空槽 + plus 图标 + 灰字「沙箱」——「往里放一个项目」的隐喻
  • 方块同时是会话头像语言的复用（列表/面板未来可同构）
优劣
  • ＋ 识别度最高：方块比文字更早被视觉捕获
  • ＋ 黑白灰内完成，avatar 语言可在侧栏/面板复用
  • － 首字母中文项目名取首字（如「博」）观感待验证
方案 F 等宽路径式 ▸ ~/qualia · 终端审美
chip 就是一行小路径：沙箱态 `~/sandbox`，绑定态 `~/项目名`，前置箭头。最安静、最工程师。

设计要点
  • mono 11px；沙箱态 text-3 灰，绑定态 text-1 近黑（字色即状态）
  • `~/sandbox` 与 `~/qualia` 同构——路径就是状态，切换 = 换路径
  • 锁定态 55% 透明 + 小锁；hover 背景提示可点
优劣
  • ＋ 与终端风视图 / 代码审美完全同语言，最耐看
  • ＋ 形态最安静，宽度随名称自然伸缩
  • － 可点击感知弱（纯文字），依赖 hover 反馈
  • － 非开发者用户对路径隐喻无感
