工作区 chip 两态样式 · 三版方案

沙箱态（未绑定，文件改动落在会话目录）与绑定态（已锚定项目）的样式语言。三版均保留交互不变：点击弹下拉（最近打开/浏览更多/移除），锁定后只读。日间 · 石墨工程

方案 A 状态色语义 琥珀=未锚定 · 绿点=已锚定
颜色直接表达「文件去哪了」：琥珀虚线 = 改动在会话目录（未锚定），绿点 = 已锚定项目。无需读字即知状态。

设计要点
  • 沙箱态：琥珀色虚线 + folder-plus，警示「改动未锚定到项目」
  • 绑定态：无边框，绿点（锚定安全）+ folder-open + 项目名灰字
  • 锁定态：灰化 + 行尾小锁，悬停提示原因
优劣
  • ＋ 状态零成本可读——扫一眼颜色就知道文件去向
  • ＋ 锁定态的锁图标语义直白
  • － 引入琥珀/绿两个语义色，工具行色彩比现在丰富
方案 B 胶囊徽章 mono 大写 · 终端工具感
chip 做成小胶囊徽章：等宽字体大写 + 状态圆点，绑定态反白实底——与终端风格视图同语言。

设计要点
  • 沙箱态：灰描边透明胶囊 + 灰点，大写 SANDBOX（等宽宽字距）
  • 绑定态：近黑实底胶囊反白（与发送按钮同体系），绿点 = 锚定
  • 锁定态：灰底胶囊 + 锁图标，不可点
优劣
  • ＋ 工具感/极客感最强，绑定态存在感清晰（实底胶囊）
  • ＋ 大写 mono 与终端 tab / 状态栏语言统一
  • － 中文环境里大写英文徽章混排（SANDBOX/QUALIA）可能显突兀
  • － 实底胶囊在工具行里视觉偏重
方案 C 纯文本流 无框无图标 · 最轻表达
chip 退化为一段状态文字：沙箱态斜体灰字，绑定态项目色条 + 项目名。靠字重与色条区分，几乎零视觉重量。

设计要点
  • 沙箱态：斜体灰字「沙箱（未绑定）」，无图标无框，hover 才浮背景提示可点
  • 绑定态：2.5px 项目色条（哈希色）+ 项目名中字重——像编辑器文件标记
  • 锁定态：色条灰化 + 小锁后缀
优劣
  • ＋ 视觉重量最轻，工具行只剩一行纯净图标
  • ＋ 项目色条可顺带做多项目区分（每项目一色）
  • － 可点击感知最弱，新用户可能不知道 chip 能点
  • － 斜体中文渲染在部分字体下发虚
