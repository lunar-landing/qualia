最近列表不再过滤当前项：当前项置顶 + 绿勾 +「使用中」徽标，点其他项即切换，移除弱化沉底。

  • － 移除与浏览仍同区混排，只是视觉弱化
方案 B 状态条 + 切换区 语义分区 · 移除归位
下拉分两段：顶部「当前工作区」状态条（移除是它右侧的小图标），下方「切换到」列表——移除是当前项的属性，切换才是主操作。

交互
  • 顶部状态条 = 当前工作区概览（含完整路径悬停）
  • 移除收缩为状态条右侧小图标——是当前项的操作，不是列表项
  • 「切换到」标题 + 纯净列表：点谁切谁，一步完成
  • 「浏览更多」打开完整弹窗（目录浏览/搜索/新建）
优劣
  • ＋ 语义最清晰：状态 / 切换 / 移除三者职责分离
  • ＋ 「切换到」标题直接回应用户心智（换工作区是主路径）
  • － 面板稍高；移除图标较隐蔽（但这正是想要的弱化）

  • － 实现成本最高（键盘导航 / 过滤 / 路径识别）
  • － 面板较宽较高，视觉存在感强
