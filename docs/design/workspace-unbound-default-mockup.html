无绑定默认工作区（Default Workspace）

目标：不再强制绑定工作区 —— 启动即可问答；仅在用户主动「绑定文件夹」时，会话才落到真实项目目录。
所有会话统一存放于 ~/.qualia/code/sessions/{sessionId}/；未绑定时会话使用自己域内的派生工作区 workspace/，绑定后指向用户选择的文件夹——存储不分桶，差别只在会话的绑定字段。

概念模型与行为变化

单一会话桶 + 绑定字段：所有会话统一存于 sessions/{sessionId}/，会话与工作区的关系由会话元数据的 workspace 字段表达——null 即使用域内派生工作区 workspace/，写入用户选择的路径即绑定外部工作区。绑定/解绑只改字段、零迁移；UI 上仍以虚线 + 沙箱徽标区分两种形态。

统一存储布局：

~/.qualia/code/
├─ sessions/{sessionId}/              ← 所有会话统一存放（不再按工作区分桶）
│    ├─ session.json                  # 元数据：workspace = null | 用户绑定的路径
│    ├─ memory.json / files/
│    └─ workspace/                    ← 派生工作区（未绑定时创建，文件工具根）
└─ workspaces.json                    ← 最近工作区列表（绑定记录，供快速切换）
维度派生工作区（未绑定）用户绑定工作区
会话存储统一 sessions/{sid}/（单一桶，两态相同）
绑定表达元数据 workspace = null（缺省）元数据 workspace = 用户选择的路径
文件工具根 sessions/{sid}/workspace/（按需创建），能力完整根 = 绑定的项目目录，具备项目上下文
隔离粒度会话级：独立 workspace/项目级：同项目多会话共享目录
启动行为直接进入聊天，不再弹出工作区选择弹窗静默复用最近有效工作区（现状不变）
绑定 / 解绑绑定 = 写入 workspace 字段；解绑 = 置回 null。只改元数据，会话数据零迁移
删除清理删会话目录即全部清理（含派生 workspace/）删会话仅删 sessions/{sid}/，外部项目目录不受影响
安全边界workspace 字段仅允许「用户显式绑定动作」（文件夹选择对话框）写入；模型输出 / 普通消息不可改写——外部路径写入即信任边界
历史记录派生形态不进 recent 列表（固定项置顶展示）照常写入 workspaces.json 供快速切换
