语义说明（白名单）：技能管理 / MCP 管理维护全局资源池；智能体创建/编辑时逐个勾选要引用的资源， 只有勾选的才对该智能体可用。
生效规则：智能体可用 = 勾选的 ∩ 全局已启用。全局禁用（灰显 + 徽标）为总开关，勾选也不可用。
数据模型：ClawAgentDefinition 新增 skills[] / mcpServers[]（按名称引用）； 字段缺失（存量智能体）= 引用全部，空数组 = 不引用任何资源； ClawAgentService.loadGlobalSkills / connectMcpServers 各加一道白名单过滤。
