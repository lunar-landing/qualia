# 文案写作风格完整规范

## 一、语气分级

| 场景 | 语气 | 示例 |
|---|---|---|
| 产品公告 | 正式、克制 | "本次更新包含 3 项改进" |
| 公众号文章 | 亲切、口语化 | "这次我们把常用功能往前挪了一步" |
| 客户邮件 | 礼貌、简洁 | "您好，附件为本周报表，请查收" |

## 二、禁用词清单

以下词汇一律不用：震撼、史上最强、秒杀全网、绝对、100%、完美无缺。

替换原则：用具体数字和事实代替主观夸张，例如把"速度飞快"改为"响应时间缩短到 0.3 秒"。

## 三、称谓与署名

- 对读者统一称"您"
- 团队自称"我们"，不用"小编"、"本司"
- 邮件署名格式：姓名 · 部门 · 联系方式

## 四、排版细则

1. 段落不超过 4 行，超过就拆段
2. 重点内容用**加粗**，不用感叹号堆砌
3. 列表项保持句式一致（都用动词开头或都用名词）
4. 中英文之间加一个空格，如"使用 Qualia 框架"
