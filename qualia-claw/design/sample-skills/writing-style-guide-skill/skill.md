# Writing Style Guide

纯文档型技能：为智能体提供公司对外文案的统一写作规范，不含脚本。

## 使用场景

当用户需要撰写或润色以下文案时，先加载本技能：

- 公众号文章、产品公告
- 客户邮件、商务函件
- 社交媒体短文

## 核心规范摘要

1. **语气**：专业但不生硬，避免过度营销词汇（"震撼"、"史上最强"等禁用）
2. **称谓**：对用户统一称"您"，团队自称用"我们"
3. **数字**：正文中的统计数字用阿拉伯数字，金额保留两位小数
4. **排版**：段落不超过 4 行，重点用加粗而非感叹号

完整的分级规范与示例见 `references/style-guide.md`，撰写长文案前请通读。

## 使用流程

1. 使用 `load_skill` 加载本技能
2. 长文案任务额外查阅附属文档 `style-guide.md`
3. 按规范产出文案后自查一遍禁用词清单
