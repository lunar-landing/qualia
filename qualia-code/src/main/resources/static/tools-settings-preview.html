工具管理界面设计预览 设计稿

此页面展示工具权限管理的 UI 设计方案。每个工具显示图标、名称、描述和启用开关，按类别分组。

设置

📖
read
读取文件内容，支持文本和图片预览
启用
🔍
grep
使用正则表达式搜索文件内容
启用
📂
glob
按文件名模式匹配查找文件
启用
✏️
replace
精确替换文件中的指定内容
启用

创建新文件或覆盖写入内容
启用
🗑️

禁用

禁用

🌍

启用
🔎

启用
提示：禁用的工具在新对话中将不可用。高风险工具（如 delete_file、bash）建议在不需要时禁用。

🎨 设计说明

  • 分组展示：工具按「文件操作」和「网络操作」分类，便于快速定位
  • 卡片式布局：每行显示一个工具，包含图标、名称、描述和开关
  • 视觉反馈：禁用的工具卡片半透明显示，状态文字切换为「禁用」
  • 图标增强：为每个工具添加语义化图标，提升可识别性
  • 底部提示：说明禁用影响和安全建议
  • 交互简化：点击开关即时切换状态，保存后生效
