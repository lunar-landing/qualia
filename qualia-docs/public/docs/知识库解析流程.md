# 知识库文件解析流程

## 1.1 基本介绍

知识库文件解析功能采用 **MinerU 结构化解析 + AI 语义分段** 的混合架构，实现从原始文档上传到可检索知识块的完整处理链路。


**核心服务职责**

| 服务 | 职责 |
|------|------|
| RagflowKnowledgeService | 主编排服务，协调整个解析流程 |
| MinioObjectStorageService | MinIO 对象存储，提供公网可访问的文件 URL |
| RagflowClient | RagFlow 知识库管理，负责文档与分段的 CRUD 操作 |
| MineruClient | MinerU HTTP 客户端，负责批量任务提交与状态查询 |
| MineruResultParser | 解析 MinerU 返回的结构化文档块 |
| AiDocumentChunkService | AI 文档分段服务，按保险语义生成知识块 |

### 1.2 处理流程

文件解析遵循以下五阶段处理流程：

**阶段一：文件上传与存储**

用户上传文件后，系统同时执行本地备份和 MinIO 对象存储上传。本地备份保存至 `data/ragflow/files/{知识库ID}/{文件ID}/` 目录，MinIO 对象存储路径为 `ragflow/files/{知识库ID}/{文件ID}/{文件名}`。系统生成有效期 72 小时的预签名 URL 供 MinerU 服务访问。

**阶段二：RagFlow 原文档创建**

调用 RagFlow API 创建 manual chunk 模式的文档占位符。此步骤确保用户在 RagFlow 界面看到的是原始文件名，且后续 AI 分段结果直接覆盖该文档的内容，避免产生重复文件。

**阶段三：MinerU 批量解析**

将 MinIO 预签名 URL 提交至 MinerU 服务进行文档结构化解析。系统通过 `batchId` 跟踪任务状态，每 60 秒轮询一次解析进度。MinerU 完成后返回 `fullZipUrl`，系统下载并解压解析结果至 `data/ragflow/mineru-results/` 目录。

**阶段四：AI 语义分段**

MineruResultParser 从解析结果中提取结构化文档块（优先读取 `content_list.json`，回退至 `full.md`）。AiDocumentChunkService 将文档块按 28,000 字符分批，每批附带 3,000 字符的上下文窗口，调用大语言模型按保险领域语义生成知识块。

**阶段五：RagFlow 同步**

将 AI 生成的知识块逐条写入 RagFlow 文档的 manual chunks，同时更新本地 `ragflow_knowledge_chunk` 表。完成后刷新知识库统计信息（文件数、分段数、总大小）。

### 1.3 状态管理

系统维护三组状态字段以追踪处理进度：

| 状态字段 | 可选值 | 说明 |
|---------|--------|------|
| `status` | pending / processing / completed / failed | 文件整体处理状态 |
| `syncStatus` | pending / synced / failed | RagFlow 同步状态 |
| `mineruState` | created / submitted / rate_limited / disabled | MinerU 任务状态 |

## 2. 集成代码示例

### 2.1 文件上传入口

```java
@Service
public class RagflowKnowledgeService {

    @Transactional
    public List<Map<String, Object>> uploadFiles(String knowledgeBaseId, 
                                                  List<MultipartFile> files) {
        RagflowKnowledgeBase base = requireKnowledgeBase(knowledgeBaseId);
        RagflowConfig config = resolveConfig(base);
        
        List<Map<String, Object>> result = new ArrayList<>();
        for (MultipartFile multipartFile : files) {
            if (multipartFile == null || multipartFile.isEmpty()) {
                continue;
            }
            
            // 1. 创建本地文件记录并上传 MinIO
            RagflowKnowledgeFile file = createMinioBackedFile(base, multipartFile);
            knowledgeFileMapper.insert(file);
            
            try {
                // 2. 创建 RagFlow 原文档
                createRagflowDocumentForManualChunks(config, base, file);
                // 3. 提交 MinerU 解析
                submitFileToMineru(file);
            } catch (Exception e) {
                // 异常处理：记录状态并继续处理下一个文件
                updateMineruSubmission(file.getId(), null, file.getId(), 
                    "failed", "failed", "failed", e.getMessage(), 
                    System.currentTimeMillis());
            }
            
            result.add(toFileMap(knowledgeFileMapper.selectById(file.getId())));
        }
        
        refreshStats(knowledgeBaseId);
        return result;
    }
}
```

### 2.2 MinerU 状态轮询

```java
@Scheduled(fixedDelay = 60_000, initialDelay = 60_000)
public void pollMineruParsingStatuses() {
    List<RagflowKnowledgeFile> files = listMineruPendingFiles();
    if (files.isEmpty()) {
        return;
    }
    
    for (RagflowKnowledgeFile file : files) {
        try {
            // 补提交未获取 batchId 的记录
            if (file.getMineruBatchId() == null || file.getMineruBatchId().isBlank()) {
                submitFileToMineru(file);
                continue;
            }
            
            // 查询并同步解析状态
            if (syncMineruParsingStatus(file)) {
                // 状态更新成功，继续处理下一个文件
            }
        } catch (Exception e) {
            if (isMineruRateLimit(e)) {
                // 触发限流，暂停本轮轮询
                break;
            }
            logger.warn("轮询 MinerU 状态失败: fileId={}, error={}", 
                file.getId(), e.getMessage());
        }
    }
}
```

### 2.3 MinerU 完成后的处理链路

```java
private void processMineruDoneResult(RagflowKnowledgeFile file, 
                                      MineruExtractResult result, 
                                      int progress) {
    RagflowKnowledgeBase base = requireKnowledgeBase(file.getKnowledgeBaseId());
    RagflowConfig config = resolveConfig(base);
    
    // 1. 下载 MinerU 结果 zip
    Path resultZip = buildMineruResultPath(file);
    mineruClient.downloadTo(result.fullZipUrl(), resultZip);
    
    // 2. 解压并提取结构化文档块
    MineruZipExtractService.ExtractResult extractResult = 
        mineruZipExtractService.extract(resultZip, buildMineruResultExtractDirectory(file));
    List<MineruDocumentBlock> mineruBlocks = 
        mineruResultParser.extractBlocks(resultZip, file);
    
    // 3. AI 语义分段
    List<RagflowChunkDto> parsedChunks = 
        aiDocumentChunkService.generateChunks(file, mineruBlocks);
    validateChunksForFile(file, parsedChunks);
    
    // 4. 覆盖 RagFlow manual chunks
    prepareDocumentForChunkOverwrite(config, base, file);
    List<RagflowKnowledgeChunk> chunks = 
        pushChunksToRagFlow(config, base, file, parsedChunks);
    
    // 5. 更新本地数据库
    knowledgeChunkMapper.deleteByFileId(file.getId());
    if (!chunks.isEmpty()) {
        knowledgeChunkMapper.batchInsert(chunks);
    }
    
    // 6. 更新最终状态
    updateMineruResult(file.getId(), result.state(), result.fullZipUrl(), 
        resultZip.toString(), progress, mineruMetadata(result), 
        "completed", "synced", null, System.currentTimeMillis());
    refreshStats(base.getId());
}
```

### 2.4 AI 分段服务调用

```java
@Service
public class AiDocumentChunkService {

    private static final int PRIMARY_BATCH_CHARS = 28_000;
    private static final int CONTEXT_CHARS = 3_000;

    public List<RagflowChunkDto> generateChunks(RagflowKnowledgeFile file, 
                                                 List<MineruDocumentBlock> blocks) {
        if (blocks == null || blocks.isEmpty()) {
            throw new IllegalArgumentException("MinerU 文档块为空，无法进行 AI 分段");
        }
        
        // 按上下文窗口分批
        List<DocumentBatch> batches = buildBatches(blocks);
        List<RagflowChunkDto> result = new ArrayList<>();
        
        for (int i = 0; i < batches.size(); i++) {
            DocumentBatch batch = batches.get(i);
            String prompt = buildPrompt(file, batch, i + 1, batches.size());
            
            // 调用大语言模型生成分段
            ChatResponse response = chatModel.chat(
                List.of(ChatMessage.user(prompt)), 
                ResponseFormatType.JSON_OBJECT
            );
            String content = firstMessageContent(response);
            result.addAll(parseChunks(content, file));
        }
        
        // 去重、重排、补齐字段
        List<RagflowChunkDto> chunks = normalizeChunks(
            removeDuplicateChunks(result), file
        );
        
        if (chunks.isEmpty()) {
            throw new IllegalStateException("AI 未生成有效 chunk");
        }
        
        return chunks;
    }
}
```

### 2.5 重新解析已存在文件

```java
@Transactional
public Map<String, Object> reparseFileWithMineru(String fileId) {
    RagflowKnowledgeFile file = requireFile(fileId);
    RagflowKnowledgeBase base = requireKnowledgeBase(file.getKnowledgeBaseId());
    resolveConfig(base);
    
    if (isBlank(file.getRagflowDocumentId())) {
        throw new IllegalStateException("文件未绑定 RagFlow 原文档，无法覆盖 chunks");
    }
    
    // 确保 MinIO 源文件存在
    ensureMinioSourceObject(file);
    // 重置 MinerU 解析状态
    resetMineruParsingState(file);
    // 重新提交解析
    RagflowKnowledgeFile refreshed = requireFile(fileId);
    submitFileToMineru(refreshed);
    
    return toFileMap(requireFile(fileId));
}
```
